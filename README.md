# MAPS | AI 데이터 매핑 고도화 실험

**MAPS**는 서로 다른 시스템의 Source 데이터와 Target 데이터 모델을 연결하는 데이터 마이그레이션 지원 프로젝트다. 시스템마다 컬럼명·자료형·업무 의미가 다르기 때문에, 데이터를 옮기기 전에는 **어떤 컬럼을 어디로 이관하고 어떻게 변환할지** 정의해야 한다.

이 저장소는 두 가지 문제를 구분해 연구한다.

- **매핑 추천:** 이미 정의된 표준·업무 지식과 매핑 관계를 활용할 때 Source–Target 연결을 얼마나 정확히 제안할 수 있는가?
- **매핑정의서 작성:** 승인된 매핑 관계가 없는 상태에서 Target 선택·이관 여부·변환 규칙의 초안을 얼마나 자동으로 작성할 수 있는가?

현재까지 세 가지 실험을 수행했다. **사전학습 모델 비교 → 그래프 기반 관계 탐색 → 매핑정의서 자동 작성 기준선**으로 범위를 확장했다. 각 실험의 평가 데이터와 지표가 다르므로 아래 숫자를 하나의 성능 순위로 비교하지 않는다.

## 연구 개요

| 구분 | 핵심 질문 | 접근 방법 | 현재 상태 |
|---|---|---|---|
| **01. 사전학습 모델 비교** | 컬럼 이름 외에 설명·자료형을 활용하고 임베딩 모델을 바꾸면 매핑 품질이 개선되는가? | MPNet·다국어 E5·한국어 SRoBERTa 및 Magneto의 비LLM 매칭 구성 비교 | 실제 모델 추론·평가 완료 |
| **02. 그래프·온톨로지 실험** | 표준용어·도메인 관계와 다른 원천의 승인 이력이 후보 순위와 최종 매핑에 도움이 되는가? | 검색 기반 매칭과 경량 그래프 확산 비교 | 로컬 평가 완료, F1 개선은 미입증 |

## 01. 사전학습 모델 비교 — 컬럼 매칭의 기본 성능

### 문제 정의

데이터베이스 간 컬럼 이름이 다르거나 약어가 사용되면 단순 문자열 일치만으로는 Target을 선택하기 어렵다. **컬럼 설명과 자료형을 추가하거나, 의미를 표현하는 임베딩 모델을 변경하면 실제 매핑 판단이 개선되는지** 확인했다.

### 방법

- MPNet, 다국어 E5, 한국어 SRoBERTa의 공개 사전학습 가중치를 CPU에서 실제 실행했다. 별도 파인튜닝은 하지 않았다.
- Magneto 공개 구현의 **비LLM 스키마 매칭 구성**을 사용해 컬럼명만 제공하는 조건과 설명·자료형을 추가하는 조건을 비교했다.
- 동일한 평가 범위에서 매핑 정밀도·재현율·F1을 계산하고, 이관 제외 판단도 함께 확인했다.

### 결과

**동일한 93개 평가 질문(매핑 44개·이관 제외 49개)에서 관찰한 매핑 F1**

| 방법 | F1 |
|---|---:|
| MPNet · 컬럼명만 사용 | 43.2% |
| MPNet · 컬럼명 + 설명 + 자료형 | 65.2% |
| 다국어 E5 · 동일한 메타데이터 | **65.9%** |
| 한국어 SRoBERTa · 동일한 메타데이터 | 40.9% |

**해석:** 모델을 바꾸는 것보다 **적절한 메타데이터를 제공하는 효과가 크게 관찰**됐다. 동일 메타데이터에서 E5와 MPNet의 F1 차이는 작아, 이 결과만으로 E5가 일반적으로 우수하다고 결론 내리지 않는다.

별도로 기존 RAG 출력이 남아 있는 18개 질문에서는 저장된 기존 출력과 신규 모델을 비교했다. 이 비교는 전체 93개 질문에 대한 기존 RAG의 최종 성능 비교가 아니다. 본 실험은 LLM 재정렬·운영 환경 마이그레이션·새로운 원천에 대한 일반화 성능을 입증하지 않는다.

## 02. 그래프·온톨로지 실험 — 관계 정보의 추가 가치

### 문제 정의

컬럼명이 비슷해도 업무 의미가 다르면 잘못된 Target을 선택할 수 있다. **표준용어·단어·도메인 관계와 다른 Source 시스템에서 승인된 매핑 이력**이 이 문제를 개선하는지 검증했다.

### 방법

- 표준 개념과 Target 컬럼의 관계를 경량 그래프로 구성하고, 검색 점수에 관계 기반 점수를 결합했다.
- 다른 원천의 승인 이력을 활용하는 조건과 그래프를 추가하는 조건을 구분했다.
- 5개 Source 시스템을 번갈아 평가에서 제외하는 방식으로 해당 시스템의 정답 연결이 추천에 직접 사용되지 않도록 구성했다.
- **114개 평가 질문, 매핑 대상 65개, 승인 관계 68쌍, 이관 제외 49개, Target 후보 78개**를 평가했다.

### 결과

| 방법 | Top-1 적중률 | Top-5 적중률 | 매핑 F1 |
|---|---:|---:|---:|
| 메타데이터 TF-IDF | 41.5% | 75.4% | 36.6% |
| 기존 승인 이력 결합 | 64.6% | 89.2% | **54.0%** |
| 용어·단어·도메인 그래프 | 66.2% | 83.1% | 42.9% |
| 그래프 + 다른 원천 승인 이력 | **69.2%** | **92.3%** | 51.8% |

**해석:** 그래프와 이력을 결합한 경우 Top-1·Top-5 후보 적중률은 개선됐지만, **매핑 F1은 승인 이력만 사용한 방식보다 2.2%p 낮았다.** 따라서 그래프 도입으로 전체 매핑 정확도가 향상됐다고 주장할 수 없다.

Top-K 적중률은 올바른 후보가 추천 목록에 포함됐는지 측정하는 지표다. **Top-K 개선은 곧바로 확정 매핑의 정확도나 실제 이관 성공을 의미하지 않는다.** 또한 평가에 사용한 표준 지식과 규칙은 이미 프로젝트 자료를 참고해 구성되어 있어 독립된 외부 데이터 검증이 필요하다.

[실험 코드와 결과 확인](experiments/maps-graph-lab/)

## 03. 매핑정의서 초안 자동 생성 — 기존 매핑 관계 없이 시작하기

### 문제 정의

앞의 두 실험은 주로 **Source–Target 매핑 후보를 더 잘 찾는 방법**을 다뤘다. 그러나 실제 데이터 마이그레이션에는 연결 후보뿐 아니라 **이관 여부·변환 방식·예외 처리**를 명시한 매핑정의서가 필요하다.

세 번째 실험에서는 기존 승인 매핑정의서를 생성 알고리즘에 제공하지 않고, Source·Target 메타데이터만으로 초안을 작성할 수 있는 범위를 확인했다.

### 방법

- 컬럼명 문자 n-gram TF-IDF, 약어 유사도, 컬럼 설명 유사도를 결합해 Target 후보를 계산했다.
- 자료형 호환성과 테이블 단위의 유사도를 반영하고, 점수·후보 간 차이·근거의 충분성을 검사했다.
- 명시적 근거로 판단할 수 있는 경우에만 `MIGRATE` 및 `COPY`·`FORMAT`을 제안하고, 정보가 부족하면 `REVIEW`로 보류했다.
- 구현 코드는 Claude의 개발 보조를 받아 작성했지만, **실제 매핑 추론은 외부 LLM을 호출하지 않는 Python 규칙·유사도 알고리즘**으로 수행했다.

### 결과

**Source 140개 컬럼 / Target 78개 컬럼에 대한 초안 생성**

| 판정 | 건수 | 의미 |
|---|---:|---|
| `MIGRATE` | **4 (2.9%)** | COPY 3건·FORMAT 1건을 자동 작성한 *승인 전 후보* |
| `REVIEW` · Target 후보 식별 | 8 (5.7%) | Target을 제안했으나 변환 규칙 미확정 |
| `REVIEW` · Target 미확정 | 128 (91.4%) | 추가 업무 근거나 검토 필요 |
| `EXCLUDE` | 0 | 명시적인 제외 규칙이 입력되지 않음 |

전체 140개에 대한 JSON 초안은 생성했지만, **변환 규칙까지 자동 작성된 항목은 4개에 불과**했다. 일부 자동 이관 후보에도 미확정 업무 조건이 있어 실무 승인으로 간주할 수 없다.

합성 단위 테스트 **28/28**, 출력 구조 검증 **21/21**을 통과했다. 이는 코드 동작과 출력 형식에 관한 검증이며 **기존 승인 매핑과의 일치도, 실제 변환값 정확도, 전문가 수용률은 아직 측정하지 않았다.**

**해석:** 기존 검색만으로는 완성된 매핑정의서를 자동 작성하기 어렵다는 한계가 확인됐다. 특히 코드 대응표·식별자 정책·복잡한 변환 규칙처럼 업무 지식이 필요한 부분은 단순 유사도로 확정할 수 없다.

[실험 코드와 합성 테스트 확인 — PR #1 검토 중](https://github.com/yurimakes/maps-model-evaluation/tree/feature/exp1-rule-baseline-reviewed/experiments/mapping-spec-generation/exp1-rule-baseline/)

## 세 실험에서 확인한 점

| 연구 관점 | 현재까지의 결과 |
|---|---|
| **입력 정보의 중요성** | 컬럼명만 사용할 때보다 설명·자료형을 추가한 조건에서 매핑 F1이 크게 높아졌다. |
| **복잡한 기술의 추가 가치** | 그래프는 후보 순위에 기여했지만, 확정 매핑 F1 개선은 확인되지 않았다. |
| **업무 자동화의 남은 과제** | 후보 검색과 매핑정의서 자동 작성은 다르며, 이관 판단과 변환 규칙 작성에는 추가 업무 근거·검증이 필요하다. |

## 검증 범위와 다음 단계

현재의 수치는 각각의 **서로 다른 평가 범위**에서 얻은 결과다. 93개 질문의 사전학습 모델 비교, 114개 질문의 그래프 실험, 140개 Source의 정의서 초안 생성 결과를 하나의 정확도 비교표로 합산하지 않는다. 이전에 저장된 RAG 응답의 재채점, 실제 사전학습 모델 추론, 규칙 기반 초안 생성도 구분한다.

다음 단계는 **세 번째 실험의 매핑정의서 초안을 기존 승인 정의서와 독립적으로 대조**하는 것이다. 이때 Source 식별자 차이를 정리하고 Target 매핑 일치도, 이관 여부, 변환 연산을 나눠 평가한다. 이후 실제 변환 결과를 검증할 수 있는 사례에 한해 실행 정확도를 확인하고, 오류 유형에 따라 논문 기반 SQL·변환 규칙 생성 방식을 추가 검토한다.

여기 기록한 성능은 특정 평가셋에서 관찰한 결과이며, 현업 전체에서의 정확도·마이그레이션 완료율·업무시간 절감 효과를 의미하지 않는다.
