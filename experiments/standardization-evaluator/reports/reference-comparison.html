결과를 읽을 때

‘차이’는 의미 오류 확정이 아닙니다. 코드 체계·약어·도메인 정책 차이도 포함됩니다. 예를 들어 용어는 이름과 약어를 모두, 코드는 그룹명과 코드값을 함께 비교했습니다.

공공표준 100%는 ‘사전에 있는 선택 항목의 등록 내용과 같다’는 뜻입니다. 해당 원천 컬럼에 적절한 항목을 선택했다는 뜻은 아닙니다. 사전 미등록 신규 후보는 자동 오답으로 세지 않았습니다.

공공표준 사전만으로 컬럼 연결과 개별 코드 대응의 정답을 만들 수 없어 해당 영역은 미측정입니다. 단어는 구성 순번 기준의 부분 대조입니다.

팀원 공유용 요약입니다. 원천 데이터·정답지·항목별 상세 CSV는 포함하지 않았습니다.
