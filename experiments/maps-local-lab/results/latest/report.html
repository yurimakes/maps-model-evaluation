해석과 다음 실험

문자 TF-IDF는 학습된 의미 임베딩 모델이 아닙니다. 하이브리드도 BM25와 문자 유사도를 결합한 로컬 구현입니다. 규칙은 자료형 불일치를 약하게 감점하며, 업무상 이관 제외 정책 전체를 구현하지는 않습니다. 자동 승인 기준으로 사용하기 전 오답·보류를 검토해야 합니다.

다음 단계는 같은 평가 인터페이스에서 한국어 임베딩과 실제 2차 RAG 예측을 추가하고, 새 업체 데이터 또는 사람이 별도로 검토한 정답셋으로 비교하는 것입니다. AI Hub 상담 코드화는 컬럼 매핑과 별도 과제이며, 이 실행에는 포함하지 않았습니다.

Magneto 공식 저장소의 문자열 비교 함수를 가져와 기준 방법으로 실제 실행했습니다. 신경망 검색·LLM 재정렬을 포함한 Magneto 전체나 LLMatch 전체를 재현한 것은 아닙니다. 사용 코드 출처 · 검토한 LLMatch
