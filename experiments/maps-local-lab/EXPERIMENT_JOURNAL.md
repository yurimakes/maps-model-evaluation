# 실험 기록 · 2026-10-29

1. 프로젝트 sources 폴더가 비어 있어 이전 프로젝트 대화에 기록된 원본 경로와 사용자가 지정한 폴더의 2차백업파일.zip을 확인했다.
2. 제공 ZIP의 매핑 123행, 표준사전, Target 78컬럼, 기존 반복 로그 2종을 읽었다. 바탕화면 1016 자료의 원천 5종과 메타데이터를 확인했다. 원본은 수정하지 않았다.
3. 이름 비교, 메타데이터 TF-IDF, 사전·BM25 결합, 자료형 검사, 교차 원천 승인 이력을 비교했다. 각각의 매핑 F1은 0.263566 / 0.366412 / 0.437500 / 0.437500 / 0.540146이었다. 이것은 기존 2차 RAG와의 전체 비교가 아니다.
4. 기존 홈페이지 18질문에서 2차 반복 로그가 초기 로컬 방법보다 우수함을 확인했다. 기존 코드 재실행이 아닌 로그 재채점이며 조건 차이가 있다.
5. 사용자가 2차 고도화 목적을 재확인했다. 기존 2차 RAG 코드는 팀원에게 요청한 상태다. 2차 확정 논리모델과 업무관계 Gate를 분리된 정책으로 연결하는 실험을 추가했다.
6. 업무관계 정책 추가 후 전체 114질문의 Top-1 순위 정확도는 62/65, 매핑 F1은 0.708333이었다. 이 정책은 프로젝트 자료와 초기 오류를 검토한 후 추가했으므로 탐색 실험이다.
7. 사용자가 모든 코드·테스트·실행 스냅샷의 비공개 GitHub 보존을 요청했다. 라이브러리는 설치 버전을 기록하고 소스·평가 입력·전체 결과·검사 로그를 버전 관리한다.

초기 패키지 설치는 일반 실행 환경의 네트워크 제한으로 실패했고, 승인된 실행 환경에서 설치에 성공했다. 설치 폴더의 상속 권한을 복구한 뒤 정상 실행했다. 이 환경 설정 과정은 모델 성능 비교의 실행 시간에 포함하지 않는다.
